# Affine AimeIO 协议文档

## 1.传输方式

采用HID方式传输，上传固定为64字节，下发固定为32字节。

示范的USB描述符：

```
        0x06, 0xCA, 0xAF,  // Usage Page (Vendor Defined 0xFFCA)
        0x09, 0x02,        // Usage (0x02)
        0xA1, 0x01,        // Collection (Application)

        0x85, 0x04,        // Report ID 4 (Input 32 bytes)
        0x06, 0xCA, 0xAF,
        0x09, 0x43,
        0x15, 0x00,
        0x25, 0xFF,
        0x75, 0x08,
        0x95, 0x40,        // 64 bytes
        0x81, 0x02,        // Input (Data,Var,Abs)

        0x85, 0x05,        // Report ID 5 (Output 32 bytes)
        0x06, 0xCA, 0xAF,
        0x09, 0x44,
        0x15, 0x00,
        0x25, 0xFF,
        0x75, 0x08,
        0x95, 0x20,        // 32 bytes
        0x91, 0x02,        // Output (Data,Var,Abs)

        0xC0               // END_COLLECTION
```

其中，Vendor （0xFFCA）和 Usage （0x02）是识别设备的标志。

## 2.协议

```
typedef union{
    uint8_t raw_data[64];
    struct{
        uint8_t Start;
        uint8_t cmd;
        union{
            struct{
                uint8_t Card_Type;
                uint8_t Card_RawData[3][16];
            };
            struct{
                uint8_t Reader_Type;
                uint8_t Firmware_Vision;
                uint8_t Flash_Data[16];
            };
            struct{
                uint8_t status;
                uint8_t unused[18];
            };
        };
    };
}AimeIO_Up_t;

typedef union{
    uint8_t raw_data[32];
    struct{
        uint8_t Start;
        uint8_t Cmd;
        union{
            uint8_t Flash_data[16];
            uint8_t Write_Card_Serial[10];
            struct{
                uint8_t LED_R;
                uint8_t LED_G;
                uint8_t LED_B;
            };
        };
    };
}AimeIO_Down_t;
```

所传输的数据，首字节必须是0xff，第二个字节是CMD。有如下种类的CMD：

```
enum{
    Aime_IO_CMD_Find_Card = 0x01,
    Aime_IO_CMD_Write_Card = 0x02,
    Aime_IO_CMD_Flash_Read = 0x70,
    Aime_IO_CMD_Flash_Write = 0x71,
    Aime_IO_CMD_LED = 0x60,
    Aime_IO_CMD_JUMP2DFU = 0x61,
};
```

## 3.命令内容与解析

### 3.1 Aime_IO_CMD_Find_Card

此命令是由读卡器发给上位机。读卡器在找到卡片时主动发送此命令，上位机无需回复。

```
typedef union{
    uint8_t raw_data[64];
    struct{
        uint8_t Start;
        uint8_t cmd;
        union{
            struct{
                uint8_t Card_Type;
                uint8_t Card_RawData[3][16];
            };
```

在CMD后的一字节指明卡片类型，有如下种类：

```
enum{
    AimeIO_Card_None = 0x00,
    AimeIO_Card_Type_Aime = 0x01,
    AimeIO_Card_Type_Bana_New = 0x02,
    AimeIO_Card_Type_Bana_Old = 0x03,
    AimeIO_Card_Type_AIC  = 0x04,
    AimeIO_Card_Type_EPass = 0x05,
    AimeIO_Card_Type_Nesica = 0x06,
    AimeIO_Card_Type_Tunion = 0x07,
    AimeIO_Card_Type_Jubeat = 0x08,
    AimeIO_Card_Type_Unknow_Mifare = 0x09,
    AimeIO_Card_Type_Blank_Mifare = 0x10,
    AimeIO_Card_Type_Unknow_Felica = 0x11,
};
```

#### 3.1.0 AimeIO_Card_None

 没有找到卡。这种命令应该只在上次轮询时有卡，而这次没有卡时，发送一次，以表示状态切换。

#### 3.1.1 AimeIO_Card_Type_Aime

Card_RawData[0]的前4字节为卡片UID，后12字节为制造商信息。制造商信息没有作用。

Card_RawData[1]的信息没有特殊作用。

Card_RawData[2]前6字节无用，后10字节是以HEX格式存储的明文卡号。

例如，原始数据为0x00000000000011223344556677889900，则卡号为11223344556677889900。

这种卡的卡号必定不为3开头。

#### 3.1.2 AimeIO_Card_Type_Bana_New

Card_RawData[0]的前4字节为卡片UID，后12字节为制造商信息。制造商信息没有作用。

Card_RawData[1]的信息与卡片的加密数据相关，但不需要解析。

Card_RawData[2]前6字节无用，后10字节是以HEX格式存储的明文卡号。

例如，原始数据为0x00000000000011223344556677889900，则卡号为11223344556677889900。

这种卡的卡号必定为3开头。

#### 3.1.3 AimeIO_Card_Type_Bana_Old

Card_RawData[0]的前4字节为卡片UID，后12字节为制造商信息。制造商信息没有作用。

Card_RawData[1]的信息与卡片的加密数据相关，但不需要解析。

Card_RawData[2]是加密过后的卡号，解密方法这里略过。

这种卡的卡号必定为3开头。

#### 3.1.4 AimeIO_Card_Type_AIC

Card_RawData[0]的前8字节为卡片UID（或称IDm），后8字节为卡片PMm。

Card_RawData[1]是加密过后的卡号。它存储在原始卡片的SPAD区块里。

```
void decrypt_accesscode(uint8_t *spad)
{
    for (uint8_t i = 0; i < 16; i++)
    {
        spad[i] = S_BOX_INV[N_TABLES][spad[i]];
    }
    uint8_t count = (spad[15] >> 4) + 7;
    uint8_t table = spad[15] + ITER_ADD * count;
    for (uint8_t iter = 0; iter < count; iter++)
    {
        table -= ITER_ADD;
        {
            uint8_t prior = spad[14];
            for (uint8_t i = 0; i < 15; i++)
            {
                uint8_t temp = spad[i];
                spad[i] = (spad[i] >> 5) | ((prior & 0x1F) << 3);
                prior = temp;
            }
        }
        for (uint8_t i = 0; i < 15; i++)
        {
            spad[i] = S_BOX_INV[table % N_TABLES][spad[i]];
        }
    }
}
```

Card_RawData[0]的前4字节为卡片UID，后12字节无用。

#### 3.1.8 AimeIO_Card_Type_Jubeat

Card_RawData[0]的前4字节为卡片UID，后12字节为制造商信息。制造商信息没有作用。

Card_RawData[1]和[2]的信息与卡片的加密数据相关，作用未知。

这种卡的真实卡号不知道应该如何解密，因此使用拟造的卡号，规则如下：

```
uint8_t jubeat_serial_buffer[8];
memcpy(jubeat_serial_buffer,Card.iso14443_uid4,4);
hex_to_accesscode(jubeat_serial_buffer ,res.block+6);

void hex_to_accesscode(uint8_t *hex ,uint8_t *accesscode){
    accesscode[0] = 0x00;
    accesscode[1] = 0x00;
    memcpy(accesscode + 2, hex, 8);
    for(uint8_t i = 0;i<8;i++){
        uint8_t tmp_high = (hex[i] >> 4);
        uint8_t tmp_low = (hex[i] & 0b1111);
        if(tmp_high >= 10){
            tmp_high -= 7;
        }
        if(tmp_low >= 10){
            tmp_low -= 7;
        }
        accesscode[i+2] = tmp_high << 4 | tmp_low;
    }
}
```

其原理是使用4字节的UID造出8字节的serial，然后末尾再填充2个字节的0，并且按照长度10的以HEX格式存储的明文卡号的方式读取。

```
    AimeIO_Write_Status_Wrong_KeyA = 0x03,
    AimeIO_Write_Status_Wrong_KeyB  = 0x04,
    AimeIO_Write_Status_Write_Failed  = 0x05,
};
```

0X01的意思是没找到任何Mifare卡，0X02的意思是没有跟上次一样的卡片（卡片在这个过程中被挪走了）

### 3.3 Aime_IO_CMD_Flash_Read

读取读卡器内部Flash的数据。

上位机首先下发指令：

```
typedef union{
    uint8_t raw_data[32];
    struct{
        uint8_t Start;
        uint8_t Cmd;
    };
}
```

示例：FF 05

读卡器收到后，以相同的CMD进行回复。

```
typedef union{
    uint8_t raw_data[64];
    struct{
        uint8_t Start;
        uint8_t cmd;
        union{
            struct{
                uint8_t Reader_Type;
                uint8_t Firmware_Vision;
                uint8_t Flash_Data[16];
            };
        };
    };
}
```

其中，Reader_Type是读卡器的实际型号，已经写死在固件中。有如下型号：

```
enum{
    Monica_OpenSource = 0xA1,
    Monica_Lite = 0xA2,
    Monica_Standard = 0xA3,
    Monica_Pro = 0xA4,
};
```

Firmware_Vision为固件版本号。但这个版本号不代表实际版本号，它的作用是，每次启动时与Flash.firmversion_1进行比对，如果不一致，就往Flash里面写入默认参数的数据，覆盖原先的设置。

```
typedef union{
    uint32_t raw_flash_word[4];
    uint8_t raw_flash_byte[16];
    struct{
        uint8_t firmversion_1;
            //firmversion 低字节
        uint8_t firmversion_2;
            //firmversion 高字节
        uint8_t system_setting;
            //UART baudrate. 0x0: 115200; 0x1: 38400 ; 0x2: 9600
        uint8_t gobal_LED_setting;
            //LED Brightness
        uint8_t sega_setting;
            //BIT0:tn32 emulator enable. 0:15693(tn32 disable)
            //bit1:felica amusemunt card (AIC) tansform to real serial in sega mode. 0:disable 1:enable
            //bit2:unused
            //bit3:nesica(mifare ultra light)support enable. 0:disable
            //bit4:e-amusement-pass(iso15693)support enable. 0:disable
            //bit5:T-union(交通联合,iso14443-a,APDU)support enable. 0:disable
            //bit6:Jubeat China(mifare)support enable. 0:disable
        uint8_t spice_setting;
            //BIT0:2P mode enable. 0:1P
            //bit1:clasic aime(mifare)support enable. 0:disable
            //bit2:banapass(mifare)support enable. 0:disable
            //bit3:nesica(mifare ultra light)support enable. 0:disable
            //bit4:unused
            //bit5:T-union(交通联合,iso14443-a,APDU)support enable. enable. 0:disable
            //bit6:Jubeat China(mifare)support enable. 0:disable
        uint8_t namco_setting;
            //BIT0:todo
            //bit1:clasic aime(mifare)support enable. 0:disable
            //bit2:banapass(mifare)support enable. 0:disable
            //bit3:nesica(mifare ultra light)support enable. 0:disable
            //bit4:unused
            //bit5:T-union(交通联合,iso14443-b)support enable. 0:disable
            //bit6:Jubeat China(mifare)support enable. 0:disable
    };
}FlashData;
```

firmversion_1和firmversion_2共同组成版本号，例如firmversion_1是4，firmversion_2是2，则显示的版本号应为V2.4。

### 3.4 Aime_IO_CMD_Flash_Write

```
typedef union{
```

### 3.5 Aime_IO_CMD_LED

以指定的颜色点亮读卡器的灯光。

上位机下发指令：

```
typedef union{
    uint8_t raw_data[32];
    struct{
        uint8_t Start;
        uint8_t Cmd;
            struct{
                uint8_t LED_R;
                uint8_t LED_G;
                uint8_t LED_B;
            };
    };
}
```

读卡器收到后仅执行，不回复。

### 3.6 Aime_IO_CMD_JUMP2DFU

让读卡器跳转到DFU固件下载模式。

下发指令示例：FF 61

读卡器收到后回复：FF 61

随后读卡器会断开连接并跳转到DFU模式。
